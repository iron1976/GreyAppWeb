Grey Ragdoll: A Physics-Driven Behavioural Ragdoll System for Game Engines and Simulations

Demir Bayık, Yağmur Yayla, Ahmet Akbulut, Mehmet Tuğrul Gördü

Supervisor: Tolga Kurtuluş Çapın

Project status: in development

Abstract

Grey Ragdoll is an upcoming physics-driven behavioural ragdoll system intended for game engines and simulations. Its goal is to deliver ragdoll motion that feels convincing and satisfying, rather than loose, lifeless or unresponsive. Existing approaches fall into two groups: powered (active) ragdolls that track a reference animation, and passive ragdolls that react only to gravity and collisions. Both have clear limitations in realism. This document outlines the problem, reviews these approaches, and states the objectives of the proposed system.

Keywords: ragdoll physics, active ragdolls, behavioural animation, physics-driven character control, game engines, simulation

Contents 1. Introduction · 2. Existing Approaches · 3. Limitations ·

1. Introduction

Ragdoll physics is widely used to animate characters that react to impacts, falls and other forces. The perceived quality of these reactions strongly affects immersion in games and the credibility of simulations. Grey Ragdoll addresses this by driving character behaviour through physics, so that the body responds to its environment instead of replaying fixed motion.

2. Existing Approaches

2.1 Powered / Active Ragdolls

Powered ragdolls use a reference animation as a target and apply physics-driven control to push each body part toward the position and rotation that the animation prescribes. The result is physically simulated, but it is constantly pulled toward a pre-authored pose.

2.2 Normal (Passive) Ragdolls

Passive ragdolls are affected only by gravity, collisions and the surrounding environment. No external physics-based control is applied to the body, so the character cannot attempt to balance, brace or recover.

3. Limitations of Current Solutions

Powered ragdolls. Because body parts are always driven toward a played animation, the result can look unrealistic. In balancing situations, for example, the torso appears to correct itself on its own instead of balance being achieved through foot replacement, as a real body would do.

Normal ragdolls. With no control beyond external forces, motion appears limp and unnatural. This is the least realistic of the existing options.
